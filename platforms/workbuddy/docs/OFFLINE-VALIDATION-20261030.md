## 本轮覆盖的真实产物与失败路径

- 对比暂存目录、输出目录和 ZIP 解压内容，检查连接器身份、展示字段、版本、最低版本、
  唯一 MCP 服务、传输字段、地址、图标、许可证和平台资料隔离。
- 从实际 Skill 文件解析全部必填元数据，逐值对照源元数据；正文与共享源字节一致。
- 直接篡改最终清单、MCP、Skill、图标和状态材料，验证拒绝缺失字段、错误类型、错误
  source、版本冲突、其他格式字段、固定认证头、额外服务、重复 Skill 字段和业务正文改动。
- 只在临时目录注入配置、暂存复制、压缩及 ZIP 完整性检查失败，确认旧目录和 ZIP 不变。
- 注入最终目录复制失败，确认错误向上传播；此时旧目录已被删除，旧 ZIP 尚存。
- 注入最终 ZIP 覆盖失败，确认错误向上传播，即使 ZIP 已部分覆盖也不输出成功记录。

这些结果只支持“输出替换前的失败保护”，不支持“所有写入失败保留旧产物”。
最终替换没有事务或断电恢复保证，限制已在平台 README 中说明。

## 宿主和发布状态

本轮正式宿主用例状态保持 `NOT_RUN_IN_TARGET_HOST`。
WorkBuddy 5.9.3 是首个目标环境，并非已通过认证或完整业务验收。
最终连接器 source 与 OAuth 回调绑定、真实工具发现和 `get_profile`、客户端重启和
失效重连、生成 Skill 的宿主解析、业务授权及双账号隔离，均需在宿主中继续执行。
自定义 MCP 的开发连接结果不能代替最终连接器身份验收。

不得将本次离线通过标成 `PARTIAL_TARGET_HOST` 或 `PASSED_TARGET_HOST`。
本轮未部署服务、提交商店、发布版本或更新已安装的连接器。
最终交付包哈希由构建输出记录在包外，不在此报告中循环引用自身 ZIP 哈希。
